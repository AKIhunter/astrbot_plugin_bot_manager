# Bot Manager 配套服务

本目录保存 2026-11-02 正在运行的服务版本源码，包括网页、监控采集、内部查询接口、
服务配置程序、systemd 单元和安装脚本。该服务只面向 Linux 服务器，不属于 AstrBot 插件加载目录。

## 用量、单价和免费额度

打开集成平台「用量」，可按模型筛选并查看实际模型的输入、缓存输入、输出、
Token 合计、免费 Token 与已核算金额。路由请求有底层请求明细时按实际模型展示；
旧 automatic 记录缺少实际模型信息时标为未知。

点击「配置单价」：

- 已保存的价格与额度默认收起，点击模型摘要展开；新增项自动展开。
- 模型候选覆盖已启用的对话、多模态、向量、重排、语音 Provider，
  以及 automatic 当前通过健康检查的路由模型，也支持手动填写模型名。
- 唯一对应的 Provider 自动填入；同名模型有多个连接时自行选择。
- 金额使用人民币元 / 百万 Token；留空为待配置，填写 `0` 为零价。
- 免费额度填写模型与 Provider、总量、累计起点、起点前或外部已用量、到期时间。
  额度内按免费 Token 核算，超额使用已配置单价。
- 保存读取全部项目；折叠项中缺少必填值时，页面自动展开并定位该字段。

向量模型 `text-embedding-v4` 的完整步骤见 [模型计费配置指南](../docs/model-pricing.md)。
API Key、模型连接和向量维度在 AstrBot 中配置。当前费用表按 Token 计价；
语音、图片等按秒、图片或次数计费的情况需要对应计量规则。
未核实的单价、免费额度以及未采集的历史用量需要与供应商核对。

## 安装与升级

凭据、余额账户配置、模型价格配置、SSH 密钥和历史数据库不在源码中。
服务默认监听本机，应通过既有安全访问入口使用。安装脚本涉及系统服务与服务器配置，
部署前应阅读脚本并核对自己的运行环境。

插件源码就在本仓库根目录。完整克隆仓库后，在仓库根目录执行：

```bash
sudo sh service/install-server.sh service
```

脚本直接读取 `service/` 上级的插件源码，并保留对旧部署包内
`astrbot_plugin_usage_telemetry/` 目录布局的兼容。它会复制包括 `runtime_paths.py`
在内的六个必要插件文件。不要另建长期维护的插件副本。
请先备份已有服务器配置和数据，核对运行源码；不要用旧目录覆盖新版本。

`server-panel.py` 提供插件依赖的余额、搜索事件和只读搜索汇总内部接口。
令牌仍由服务器安装流程创建，不通过公共仓库分发。

安装器要求 Linux + systemd、`astrbot` 系统用户及 `/var/lib/astrbot` 的既有布局。
其他安装布局需先适配脚本。本目录通过 `export-ignore` 排除在市场安装 ZIP 之外；
服务安装和开发使用 `git clone` 获取完整源码。

本次模型配置页面与模型发现后端对应已验证的服务版本
`20261102T123810Z-model-config`。升级时使用本仓库 `service/` 和根目录插件源码，
核对当前服务器基线；完整保留现有价格、免费额度和历史数据库。
